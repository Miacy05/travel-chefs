# 明信片素材目录

把 5 张地区明信片图片放进本目录，文件名必须严格一致（区分大小写）：

| 文件名 | 对应地区 |
| --- | --- |
| china.png | 亚洲街边摊 |
| france.png | 巴黎咖啡馆 |
| japan.png | 拉面小店 |
| italy.png | 披萨工坊 |
| mexico.png | 塔可餐车 |

## 规则

1. 图片缺失也不会报错——卡面会自动回退为「地区主题色块 + emoji 图标」，页面不会白屏、不会拉伸变形。
2. 建议尺寸约 640x400、横构图。任意尺寸都会被裁切填满容器（等比裁切，不变形）。
3. 主题色与游戏内置调色板一致效果最好：中国红 / 法国蓝白 / 日本樱粉 / 意大利暖黄绿 / 墨西哥橙。
4. 图片只在该地区全部关卡通关后才显示；未解锁地区显示占位（锁 + 问号），不会提前加载大图。

## 放置后

把 5 个 png 直接拖进本文件夹即可，不需要改代码。刷新页面 → 图鉴 → 明信片标签页查看；点已解锁卡片可弹出大图。
